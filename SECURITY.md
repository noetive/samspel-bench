# Reporting a vulnerability

Email **security@noetive.eu**. Please do not open a public issue, and do not include a working credential in the report.

Useful to include: what an attacker gains, the smallest reproduction you have, and the commit you tested against.

We aim to acknowledge within two working days and to ship a fix or a mitigation within thirty days for anything that lets an attacker read or write data they do not own, recover a credential, or execute code through the benchmark harness. We will credit you in the release notes unless you prefer otherwise.

## Supported versions

There are no releases yet. The main branch is supported.
